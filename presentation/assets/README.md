# Hình minh họa mở đầu

`federated-network.png` được tạo bằng công cụ imagegen tích hợp. Đây là hình minh họa khái niệm, không phải dữ liệu đo, activation của mô hình hay ảnh chụp triển khai. Hình được nhúng base64 vào bản HTML offline.

Prompt cuối cùng:

> Use case: scientific-educational. Create a premium editorial 3D illustration for a university presentation about federated learning for network attack detection. Landscape 16:9, high resolution. Ivory white seamless background, very soft shadows, precise architectural isometric style, tactile matte white and deep navy hardware, restrained cobalt blue and warm coral accents. Show two clearly separated local network clusters on the left and right, each with a small group of network devices and a local server with tiny abstract neural connections inside, connected by elegant flowing cobalt and coral data paths to one shared global model in the center, represented by a sophisticated floating translucent neural lattice above a compact central server. A few small cubes travel along the paths to convey model updates. The local data remains with each cluster. Clean scientific visual, substantial breathing room, impressive crafted physical miniature, crisp details, balanced and visually legible at slide scale. No lettering, no words, no numerals, no charts, no UI cards, no panels, no dark background, no neon cyberpunk, no brain, no watermark. This is an illustrative concept, not measured experimental evidence.

Các sơ đồ kỹ thuật còn lại là SVG viết trong `src/visuals.js`; các biểu đồ thực nghiệm lấy từ snapshot đã kiểm tra.
